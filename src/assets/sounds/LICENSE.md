# Sons do Metrônomo/Batuque

Amostras de percussão usadas no recurso de Metrônomo + Batuque, todas
licenciadas CC0 (domínio público — uso livre, inclusive comercial, sem
necessidade de atribuição). Fonte: bigsoundbank.com, autor Joseph Sardin.

- `zabumba-bass.mp3` — "Bass tom, #4" (pancada grave, para o golpe de
  baqueta grossa da zabumba)
- `zabumba-slap.mp3` — "High-pitched tom, 1" (pancada aguda/seca, para o
  golpe de baqueta fina da zabumba)
- `triangulo.mp3` — "Triangle #3"

Não são gravações reais de zabumba/triângulo nordestino (raras como CC0),
mas timbres de percussão próximos o suficiente para marcar o ritmo. Se no
futuro surgirem amostras mais fiéis e igualmente livres, é só substituir
os arquivos — o motor de áudio não muda.
